# ระบบซ่อมบำรุงเชิงพยากรณ์สำหรับเครื่องจักรในอุตสาหกรรม 

โปรเจกต์นี้เป็นการพัฒนาระบบซ่อมบำรุงเชิงพยากรณ์ (Predictive Maintenance - PdM) สำหรับเครื่องจักรในโรงงานอุตสาหกรรม โดยใช้ข้อมูลจากเซนเซอร์วัดความสั่นสะเทือน ระบบนี้มีการบูรณาการระหว่าง Machine Learning (Isolation Forest), การประมวลผลสัญญาณ (FFT) และมาตรฐานสากล (ISO 10816-3) เพื่อให้การตรวจสอบสุขภาพเครื่องจักรและการพยากรณ์อายุการใช้งานที่เหลืออยู่ (RUL) มีความแม่นยำสูงสุด

## ภาพรวมของโปรเจกต์

ระบบจะทำการวิเคราะห์ข้อมูลความสั่นสะเทือน (หน่วย G) จากไฟล์ .txt เพื่อตรวจจับความผิดปกติ จำแนกกลุ่มสุขภาพเครื่องจักรตามมาตรฐานสากล และพยากรณ์โอกาสที่จะเกิดความเสียหายก่อนที่จะเกิดขึ้นจริง ระบบถูกออกแบบมาเพื่อใช้งานในระดับวิศวกรรมมืออาชีพ โดยให้ผลลัพธ์ทั้งในรูปแบบ Dashboard และรายงานข้อมูลเชิงโครงสร้าง

## คุณสมบัติหลักของระบบ

- **มาตรฐาน ISO 10816-3**: แปลงค่าความเร่ง (Acceleration - G) เป็นความเร็วการสั่นสะเทือน (Velocity RMS - mm/s) พร้อมจำแนกกลุ่มความรุนแรง (Zone A, B, C, D) โดยอัตโนมัติ
- **Machine Learning Inference**: ใช้ Isolation Forest ในการตรวจจับความผิดปกติของพฤติกรรมเครื่องจักร โดยเรียนรู้จากข้อมูลประวัติย้อนหลัง
- **การวิเคราะห์ในโดเมนความถี่**: ใช้ Fast Fourier Transform (FFT) เพื่อระบุความถี่เด่น ช่วยในการวิเคราะห์หาสาเหตุรากเหง้าของปัญหา (Root Cause Analysis)
- **การติดตามการเสื่อมสภาพ**: คำนวณดัชนีการเสื่อมสภาพ (Degradation Index - DI) และพยากรณ์อายุการใช้งานที่เหลืออยู่ (Remaining Useful Life - RUL) ด้วยวิธี Exponential Smoothing
- **การบันทึกโมเดล**: สามารถบันทึกโมเดลและตัวปรับสเกลข้อมูล (.joblib) เพื่อนำไปใช้ประมวลผลข้อมูลใหม่ในอนาคตได้อย่างต่อเนื่อง
- **รายงานระดับมืออาชีพ**: สร้าง Dashboard สรุปผลภาพรวมและรายงานสรุปในรูปแบบไฟล์ CSV

## ความต้องการของระบบ

ระบบรองรับ Python 3.10 ขึ้นไป และจำเป็นต้องติดตั้ง Library ดังต่อไปนี้:

```powershell
pip install pandas numpy scipy scikit-learn matplotlib joblib
```

## ขั้นตอนการติดตั้งและใช้งาน

1. **การเตรียมสภาพแวดล้อม**: ตรวจสอบให้แน่ใจว่าได้ติดตั้ง Library ที่จำเป็นครบถ้วน
2. **การเตรียมข้อมูล**: นำไฟล์ข้อมูลความสั่นสะเทือน (A_*.txt) ไปวางไว้ในโฟลเดอร์เดียวกับไฟล์โปรแกรม
3. **การรันโปรแกรม**: รันไฟล์หลักผ่าน Command Line หรือ PowerShell:
   ```powershell
   python predictive.py
   ```
4. **ผลลัพธ์**: ระบบจะสร้างโฟลเดอร์ `pm_output_v3` เพื่อเก็บผลการวิเคราะห์ทั้งหมด

## การวิเคราะห์ผลลัพธ์

### 1. สรุปผลผ่าน Console
แสดงสถานะล่าสุดของเครื่องจักรแต่ละเครื่อง ประกอบด้วย:
- ISO Zone (Condition A/B/C/D)
- Velocity RMS (mm/s)
- Risk Level (ระดับความเสี่ยง: Normal, Warning, Alert, Critical)
- Estimated RUL (อายุการใช้งานที่เหลือโดยประมาณ เป็นชั่วโมง)
- Dominant Frequency (ความถี่เด่น เป็น Hz)

### 2. Dashboard สรุปผล (dashboard.png)
- **RMS & Risk Level**: แสดงความรุนแรงของการสั่นสะเทือนและระดับความเสี่ยงที่ตรวจพบโดย AI
- **Degradation Index**: แสดงแนวโน้มการเสื่อมสภาพของเครื่องจักรตามระยะเวลา
- **ISO Velocity Bar Chart**: กราฟแท่งเปรียบเทียบค่าความสั่นสะเทือนกับเกณฑ์มาตรฐานสากล

### 3. รายงานข้อมูล (summary.csv)
ไฟล์รายงานเชิงโครงสร้างสำหรับนำไปใช้ในระบบบริหารจัดการงานซ่อมบำรุง (CMMS) หรือวิเคราะห์ต่อใน Excel

## มาตรฐานวิศวกรรมและตรรกะการตัดสินใจ

ระบบใช้การตรวจสอบแบบคู่ขนาน (Dual-Validation):
- **การตรวจสอบทางกล**: อ้างอิงตามเกณฑ์มาตรฐาน ISO 10816-3 สำหรับค่าความสั่นสะเทือนสัมบูรณ์
- **การตรวจสอบพฤติกรรม**: ใช้ Machine Learning ตรวจจับการเปลี่ยนแปลงของรูปแบบการสั่นสะเทือนที่อาจบ่งบอกถึงปัญหา แม้ค่าความสั่นสะเทือนจะยังไม่เกินเกณฑ์ ISO

## ข้อควรระวัง
ระบบนี้เป็นเครื่องมือช่วยสนับสนุนการตัดสินใจ การตัดสินใจทางวิศวกรรมและการตรวจสอบหน้างานจริงควรดำเนินการควบคู่ไปกับคำแนะนำของระบบ โดยเฉพาะเมื่อระบบแจ้งเตือนในระดับ Critical หรือ Zone D
